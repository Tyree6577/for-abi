# Abi’s letter — single-file version

All six photos, styling, and interactive features are built into `index.html`.

## Fix an existing GitHub Pages website

1. Extract this ZIP.
2. Open your website repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload this `index.html` at the same location as the old `index.html` and commit the change.
5. Wait for GitHub Pages to finish publishing, then refresh the website.

You do not need to upload a photos folder, app.js, or style.css. Existing copies of those files may remain; this version does not use them.

For a new site, upload `index.html` to a public repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

You can also open `index.html` on your computer after extracting it. Internet access is needed only for the YouTube song.

The letter wording and corrected photo-caption order are preserved.
